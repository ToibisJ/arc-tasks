# משימות ARC

דף HTML אחד שמציג את רשימת המשימות מגיליון Google Sheets, מחולקת לפי אחראי, ומייצא את הרשימה לטקסט לוואטסאפ.

## שימוש
1. מורידים את `arc-tasks.html` ופותחים אותו בדפדפן (לחיצה כפולה).
2. בפתיחה הראשונה מדביקים את הקישור לגיליון המשימות. הקישור נשמר בדפדפן בלבד.
3. **ריענון**: מושך מחדש את כל הנתונים מהגיליון.
4. **טקסט לוואטסאפ**: מציג את כל המשימות הפתוחות לפי אחראי. אפשר להעתיק או להוריד כקובץ טקסט.

## מבנה הגיליון
לשונית ברירת המחדל: `משימות שוטפות כולל טיקט`. העמודות:
`טיקט`, `סוג`, `תאריך`, `פירוט`, `אחראי`, `תג"ב`, `דחיפות`, `סטטוס`, `הערות`.
שורה שהסטטוס שלה "בוצע" עוברת לרשימת "בוצעו" ולא נכנסת לטקסט.

הגיליון צריך להיות משותף לפחות ב"כל מי שיש לו הקישור יכול לצפות". הדף רק קורא ממנו ולא כותב אליו.
